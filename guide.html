  • ອິນເຕີເນັດ — ຕ້ອງຕໍ່ເນັດຕອນຖອດສຽງ ແລະ ໂຫຼດ B-roll/ສະຕິກເກີอินเทอร์เน็ต — ต้องต่อเน็ตตอนถอดเสียง และโหลด B-roll/สติกเกอร์

ເລີ່ມໃນ 1 ນາທີเริ่มใน 1 นาที

ເລືອກວິດີໂອ → ຕັ້ງຄ່າ → AI ຖອດສຽງ → ແຕ່ງ → Export เลือกวิดีโอ → ตั้งค่า → AI ถอดเสียง → แต่ง → Export
  1. ໜ້າຫຼັກ → ສ້າງໂປຣເຈກໃໝ່ → ແຕະເລືອກວິດີໂອหน้าหลัก → สร้างโปรเจกต์ใหม่ → แตะเลือกวิดีโอ
  2. ເລືອກ ພາສາສຽງເວົ້າ, ພາສາຊັບ ແລະ ສໄຕລ໌ → ສ້າງ Subtitle →เลือก ภาษาเสียงพูด, ภาษาซับ และสไตล์ → สร้างซับไตเติล →

  4. ໃນໜ້າແກ້ໄຂ — ກົດ Auto ✨ ໃຫ້ AI ໃສ່ emoji + ໄຮໄລ້ + SFX ໃຫ້ ຫຼື ແຕ່ງເອງในหน้าแก้ไข — กด Auto ✨ ให้ AI ใส่ emoji + ไฮไลต์ + SFX ให้ หรือแต่งเอง
  5. ກົດ Export → ບັນທຶກ/ແຊร์ລົງ TikTok, Reels, YouTubeกด Export → บันทึก/แชร์ลง TikTok, Reels, YouTube

ສ້າງໂປຣເຈກໃໝ່สร้างโปรเจกต์ใหม่

ໜ້າຕັ້ງຄ່າກ່ອນຖອດສຽງ — ຕັ້ງໃຫ້ຖືກ ຊັບຈະອອກມາດີ.หน้าตั้งค่าก่อนถอดเสียง — ตั้งให้ถูก ซับจะออกมาดี

  • ຊື່ໂປຣເຈກ — ຕັ້ງເພື່ອຫາງ່າຍພາຍຫຼັງชื่อโปรเจกต์ — ตั้งเพื่อหาง่ายภายหลัง
  • ອັບໂຫລດວິດີໂອ — ແຕະເລືອກ (MP4/MOV/AVI ≤ 10 ນາທີ)อัปโหลดวิดีโอ — แตะเลือก (MP4/MOV/AVI ≤ 10 นาที)
  • ອັດຕາສ່ວນ — 9:16 (ຕັ້ງ), 1:1, 16:9 ຕາມ platformอัตราส่วน — 9:16 (แนวตั้ง), 1:1, 16:9 ตาม platform
  • ພາສາສຽງເວົ້າ — ລາວ / ໄທ / English / Autoภาษาเสียงพูด — ลาว / ไทย / English / Auto
  • ພາສາຊັບ + Translation Mode: ບໍ່ແປ / ແປພາສາ / ສອງພາສາภาษาซับ + Translation Mode: ไม่แปล / แปลภาษา / สองภาษา
  • ການແບ່ງ Subtitle — ແບ່ງເປັນທ່ອນ ຫຼື ແບ່ງເປັນຄຳ (ສຳລັບຄາລາໂອເກะ)การแบ่งซับ — แบ่งเป็นท่อน หรือแบ่งเป็นคำ (สำหรับคาราโอเกะ)
  • ຄຳໃບ້ / ຊື່ສະເພາະ — ໃສ່ຊື່ຄົນ/ຍີ່ຫໍ້/ສະຖານທີ່ (ຄັ່ນດ້ວຍ ,) AI ຈະສະກົດໃຫ້ຖືກคำใบ้ / ชื่อเฉพาะ — ใส่ชื่อคน/แบรนด์/สถานที่ (คั่นด้วย ,) AI จะสะกดให้ถูก
  • ກວດທານ AI — ໃຫ້ Gemini ກວດສະກົດຫຼັງຖອດສຽງ (ແນະນຳ)ตรวจทาน AI — ให้ Gemini ตรวจสะกดหลังถอดเสียง (แนะนำ)
ບໍ່ມີວິດີໂອ? ກົດ “ພິມ subtitle ດ້ວຍຕົນເອງ” ກໍ່ໄດ້.ไม่มีวิดีโอ? กด “พิมพ์ซับไตเติลเอง” ก็ได้

ຖອດສຽງ & ແປถอดเสียง & แปล

🧠 ເລືອກ AI ຖອດສຽງเลือก AI ถอดเสียง

  • ♊️ Gemini AI — ແນະນຳສຳລັບຊັບລາວ (ຖອດ + ແປໂດຍກົງ)♊️ Gemini AI — แนะนำสำหรับซับ (ถอด + แปลโดยตรง)
  • ⚡️ Groq Whisper — ໄວທີ່ສຸດ + ຈັບເວລາລະອຽດ⚡️ Groq Whisper — เร็วที่สุด + จับเวลาละเอียด
  • 🧠 OpenAI Whisper — ຈັບເວລາລະອຽດ (ໄທ/ອັງກິດ)🧠 OpenAI Whisper — จับเวลาละเอียด (ไทย/อังกฤษ)

ຈາກນັ້ນແອັບຈະ: ດຶງສຽງ → ຖອດສຽງ → (ແປ) → ຈັບເວລາ → ສ້າງ Subtitle ✅จากนั้นแอปจะ: ดึงเสียง → ถอดเสียง → (แปล) → จับเวลา → สร้างซับไตเติล ✅

ແກ້ຊັບแก้ซับ

ໃນໜ້າແກ້ໄຂ ມີ 4 ແທັບ: ແກ້ຊັບ ໄທມ໌ໄລນ໌ ສໄຕລ໌ ຕຳແໜ່ງในหน้าแก้ไข มี 4 แท็บ: แก้ซับ ไทม์ไลน์ สไตล์ ตำแหน่ง

  • ແຕະປະໂຫຍກໃດໜຶ່ງ → ແກ້ຂໍ້ຄວາມ / ຕັ້ງເວລາເລີ່ມ-ສິ້ນສຸດแตะประโยคใดประโยคหนึ่ง → แก้ข้อความ / ตั้งเวลาเริ่ม-สิ้นสุด
  • ເພີ່ມ ປະໂຫຍກໃໝ່ • ລຶບ • ລວມ 2 ປະໂຫຍກ • ຕັດແບ່ງเพิ่ม ประโยคใหม่ • ลบ • รวม 2 ประโยค • ตัดแบ่ง
  • ຊັບສອງພາສາ — ແຖວ 1 ພາສາຫຼັກ, ແຖວ 2 ຄຳແປ (ຕັ້ງ style ແຍກໄດ້)ซับสองภาษา — แถว 1 ภาษาหลัก, แถว 2 คำแปล (ตั้ง style แยกได้)
  • ແປ Subtitle — ກົດແປເປັນ ລາວ/ໄທ/ອັງກິດ ດ້ວຍ Geminiแปลซับไตเติล — กดแปลเป็น ลาว/ไทย/อังกฤษ ด้วย Gemini

ສໄຕລ໌ຊັບสไตล์ซับ

ປັບໃຫ້ສວຍ ໂດດເດັ່ນ ດຶງສາຍຕາ.ปรับให้สวย โดดเด่น ดึงสายตา

🎨 ປັບໄດ້ຫຍັງແດ່ปรับได้อะไรบ้าง

  • ແມ່ແບບ (Templates) — ກົດເທື່ອດຽວສວຍ ມີຫຼາຍແບບเทมเพลต (Templates) — กดทีเดียวสวย มีหลายแบบ
  • ຟອນຕ໌ — ມີຟອນລາວ/ໄທ ຫຼາຍແບບ + ນຳເຂົ້າ font (.ttf/.otf) ຂອງເຈົ້າເອງฟอนต์ — มีฟอนต์ลาว/ไทยหลายแบบ + นำเข้า font (.ttf/.otf) ของคุณเอง
  • ສີໂຕໜັງສື • ນ້ຳໜັກ (ບາງ–ໜາສຸດ) • ຂະໜາດสีตัวอักษร • น้ำหนัก (บาง–หนาสุด) • ขนาด
  • Animation ຕອນເຂົ້າ/ອອກ — ຂຶ້ນ, ລົງ, ຊ້າຍ, ເດັ້ງ, ພິມດີດ + ປັບຄວາມໄວAnimation ตอนเข้า/ออก — ขึ้น, ลง, ซ้าย, เด้ง, พิมพ์ดีด + ปรับความเร็ว
  • ໄລ່ສี (Karaoke) — ໄຮໄລ້ທີລະຄຳຕາມຈັງຫວະ + ເລືອກສີໄຮໄລ້ไล่สี (Karaoke) — ไฮไลต์ทีละคำตามจังหวะ + เลือกสีไฮไลต์
